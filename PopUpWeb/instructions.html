🚀 Activa el modo "Siempre Arriba"

Para que las ventanas se mantengan flotando sobre otras aplicaciones, puedes optar por soluciones externas reconocidas:

  • Microsoft PowerToys : La herramienta oficial de utilidades de Windows. Usa el atajo Win + Ctrl + T.
  • Always On Top Maker : Utilidad muy pequeña y portátil que permite que cualquier ventana se mantenga sobre otras.
  • Launch On Top : Aplicación para iniciar casi cualquier programa en un estado de "siempre arriba".
  • TurboTop : Una utilidad pequeña que reside en la bandeja del sistema.
  • DeskPins : Una opción clásica y ligera para "pinchar" cualquier ventana.

Si prefieres una integración automática y nativa desde la extensión (para no tener que usar atajos de teclado cada vez), puedes activar nuestra utilidad ligera pinontop siguiendo estos pasos:

1
Descarga el instalador

Descarga install_pinontop.exe desde nuestro repositorio.

2
Ejecuta el instalador

Ejecuta install_pinontop.exe. Aprobar si el sistema solicita permisos de administrador para poder registrar la herramienta en el navegador.

3
Reinicia y Disfruta

Cierra y abre tu navegador por completo. El indicador en la extensión debería ponerse en verde .

Nota técnica: Este instalador simplemente le dice al navegador dónde encontrar la herramienta para poder fijar las ventanas automáticamente.
