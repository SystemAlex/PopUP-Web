# Política de Privacidad de PopUp WEB

Esta Política de Privacidad describe cómo la extensión de navegador PopUp WEB ("la Extensión") maneja la información del usuario.

## 1. No Recopilación de Datos Personales

La extensión PopUp WEB está diseñada para funcionar sin recopilar, almacenar, transmitir o procesar ninguna información personal identificable de sus usuarios. Todas las operaciones y funcionalidades de la Extensión se realizan localmente en su navegador y dispositivo.

## 2. Datos No Personales y Uso Funcional

La Extensión puede interactuar con la configuración de su navegador y el contenido de las páginas web para realizar sus funciones principales, como:

- Abrir nuevas ventanas del navegador.
- Modificar temporalmente cabeceras de seguridad (como `X-Frame-Options` o `Content-Security-Policy`) para permitir la visualización de contenido en ventanas flotantes.
- Ajustar las dimensiones de las ventanas.

Esta interacción es estrictamente funcional y necesaria para el funcionamiento de la Extensión. No implica la recopilación de datos sobre su historial de navegación, preferencias personales, o cualquier otra información que pueda identificarle.

## 3. CompanionApp (Aplicación Compañera Opcional)

La aplicación compañera (`pinontop`) es una herramienta opcional que se instala localmente en su sistema para habilitar la funcionalidad "Siempre Arriba". Esta aplicación también opera sin recopilar ni transmitir datos personales. Su única función es interactuar con el sistema operativo para gestionar el estado de las ventanas, manteniéndolas visibles sobre otras aplicaciones.

## 4. Permisos de la Extensión

PopUp WEB requiere ciertos permisos para funcionar correctamente (por ejemplo, acceso a las pestañas del navegador, capacidad de crear nuevas ventanas). Estos permisos se utilizan exclusivamente para proporcionar las funcionalidades descritas y no para acceder, recopilar o transmitir datos personales.

## 5. Cambios en esta Política de Privacidad

Cualquier cambio futuro en esta Política de Privacidad será reflejado en esta página. Se recomienda revisar esta política periódicamente.
